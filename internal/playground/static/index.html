    Batch

    POST /ns/{ns}/batch

    Items: resource, exactly one of ifMatch / ifNoneMatch:"*", and steps (patch sets or "delete"). Optional config {ifMatch, patches} and source {ns, at}. Dry run is ?dry-run=1: it reports the ids a submit would produce and writes nothing.
